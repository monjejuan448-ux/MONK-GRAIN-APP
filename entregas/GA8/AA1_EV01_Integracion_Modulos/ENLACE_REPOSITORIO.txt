Levantar el sistema entero
--------------------------
  git clone https://github.com/monjejuan448-ux/MONK-GRAIN-APP
  cd MONK-GRAIN-APP
  cp .env.example .env
  docker compose up -d

  docker compose exec backend alembic upgrade head
  docker compose exec backend python -m app.db.seed
  docker compose exec backend python -m app.db.demo_data

  http://localhost:3000        el sitio
  http://localhost:8000/docs   la API con Swagger
  http://localhost:8025        el correo de desarrollo
