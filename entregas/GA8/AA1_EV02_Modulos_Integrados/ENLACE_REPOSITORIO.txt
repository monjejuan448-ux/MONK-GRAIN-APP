MODULOS.md no se escribe a mano. Para regenerarlo:
  docker compose up -d
  curl -s http://localhost:8000/openapi.json > openapi.json
  docker compose exec backend pytest -q --junitxml=/tmp/junit.xml
  docker compose exec backend cat /tmp/junit.xml > junit.xml
  python3 entregas/GA8/AA1_EV02_Modulos_Integrados/generar_modulos.py \
          openapi.json junit.xml \
          entregas/GA8/AA1_EV02_Modulos_Integrados/MODULOS.md
